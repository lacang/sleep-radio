# 睡前收音机

一个只为睡前用的中文电台 PWA。点一下就开始放，设个定时自己淡出，然后把手机扣在床头。

线上：https://lacang.github.io/sleep-radio/

## 现在有什么

48 个台，四组：

- **新闻 · 财经**（7）中国之声、经济之声、北京新闻、广东新闻、珠江经济、第一财经、股市广播
- **音乐**（24）经典 947 / 1037、古典乐、各地音乐广播、动感 101 等
- **评书 · 故事**（11）小说评书、沧州长书、济南故事、上海曲艺、合肥/山西/芜湖故事等
- **网络台**（6）AsiaFM、动听音乐、云梦音乐、星空电台、BIG MIX、华语之声

## 特点

- 选台一律是 mp3 直流，走原生 `<audio>`，不引 hls.js，不依赖 CORS
- 音量不做应用内调节，直接走系统音量
- 睡眠定时，最后 60 秒渐弱
- 断流自动重连（5 秒看门狗，20 秒无进度就换新连接）
- 外壳离线可用，音频流不缓存

## 界面

- 手机：顶部分组标签 + 宫格，一屏看完一组，不用长滚
- 平板（≥900px）：四组纵向平铺，一屏看全

## 本地开发

```bash
python3 -m http.server 8811
# 打开 http://127.0.0.1:8811/
```

## 发版注意

改 `index.html` / `style.css` / `app.js` 之后必须把 `sw.js` 里的 `CACHE` 版本号加一，
否则已安装的客户端走缓存优先，拿不到新版本。
