# 睡前收音机

几个中文台，加上白噪音，陪你睡觉。

## 为什么是这个东西

不是为了听全世界的电台，是为了躺下之后有个声音。

- **轻音乐 / 古典** — 6 个台
- **评书 / 故事 / 曲艺** — 6 个台
- **新闻 / 财经** — 5 个台
- **白噪音** — 棕噪音、粉红噪音、雨声、电扇声（本地合成，不走网络）

## 特点

- 电台是 mp3 直流，用原生 `<audio>` 播放，不需要 hls.js，没有 CORS 问题
- 白噪音用 Web Audio 本地合成，永不失效、不耗流量
- 睡眠定时：到点前 60 秒开始渐弱，不会突然断掉
- 锁屏 / 蓝牙耳机 / 车机 都能控制（Media Session）
- 断流自动重连
- 纯静态，无后端、无统计、无 Cookie
- 可装到主屏当 PWA

## 加台 / 删台

改 `stations.json` 就行。台站是 mp3 直链即可。

白噪音的 `noise` 字段可选 `brown` / `pink` / `rain` / `fan`。

## 本地跑

```bash
python3 -m http.server 8000
```

打开 http://localhost:8000

## 部署

任何静态托管都行。GitHub Pages：仓库 Settings → Pages → 选 main 分支根目录。

因为全部用相对路径，部署在子路径下也能正常工作。

## 说明

电台流来自公开的互联网广播地址，本项目只做播放，不转播、不分发音频内容。
